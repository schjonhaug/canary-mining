# Security Policy

Canary Mining is self-hosted mining infrastructure. Keep Bitcoin Core RPC
private, do not expose the dashboard to the public internet, and expose the SV2
listener only to miners you control.

Please report security issues privately to the project maintainer instead of
opening a public issue with exploit details. Include the affected version,
configuration shape, and enough detail to reproduce the issue.

Supported public release:

- `1.0.x`

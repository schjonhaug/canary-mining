# Miner Logos

Some miner logos in this folder were recreated from font-inspired vector
artwork rather than copied directly from source logo files. The font matches
are approximate: the original logos do not align perfectly with the fonts, so
the recreated SVGs include manual shape, spacing, and alignment adjustments.

Current font inspirations and attributions:

- NERD lettering: inspired by Gloria Hallelujah, created by
  [Kimberly Geswein](https://kimberlygeswein.com/downloads/kg-gloria-hallelujah/).
- OCTAXE lettering: inspired by the OCTAXE reference font used during the
  recreation work.
- ECO lettering: inspired by FIFA Welcome, credited to hacker2009i.

Treat these as recreated logo assets with font inspiration, not exact text
renderings from the listed fonts.
